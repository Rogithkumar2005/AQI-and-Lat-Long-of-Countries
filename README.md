# 🌍 Global Air Quality Index (AQI) Analysis

An end-to-end data science and spatial analysis project focused on inspecting global Air Quality Index (AQI) measurements alongside geographic coordinates (Latitude and Longitude). This project leverages machine learning libraries to clean environmental dataset records, explore pollutant correlations, and build predictive models for key atmospheric indicators.

---

## 🚀 Key Features

* 🧹 **Data Preprocessing & Cleaning**: Automates dataset loading, handling missing values, and formatting structural features.
* 📊 **Pollutant Correlation Analysis**: Evaluates linear and non-linear relationships between primary air pollutants (Ozone, $\text{CO}$, $\text{NO}_2$, and $\text{PM}_{2.5}$) and global AQI.
* 🗺️ **Geospatial Insights**: Maps ambient air quality metrics across geographical coordinates (latitude and longitude).
* 🤖 **Predictive Modeling**: Employs Scikit-Learn algorithms and NumPy/Pandas pipelines to estimate air quality levels.

---

## 🛠️ Tech Stack & Dependencies

* **Language**: Python 3.11+
* **Data Processing**: Pandas, NumPy
* **Visualization**: Matplotlib, Seaborn
* **Machine Learning**: Scikit-Learn
* **Model Persistence**: Joblib

---

## 📈 Dataset Overview

The dataset contains environmental AQI readings along with geospatial identifiers:

| Feature Name | Description |
| --- | --- |
| **AQI Value** | Overall Air Quality Index rating |
| **CO AQI Value** | Carbon Monoxide specific sub-index |
| **Ozone AQI Value** | Ozone ($\text{O}_3$) specific sub-index |
| **NO2 AQI Value** | Nitrogen Dioxide specific sub-index |
| **PM2.5 AQI Value** | Fine Particulate Matter ($\text{PM}_{2.5}$) sub-index |
| **lat / lng** | Geographic location coordinates |
